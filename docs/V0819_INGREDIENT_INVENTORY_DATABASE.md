# V0.8.19 食材 / 库存数据库统一

本轮以正式主分支现有食材为唯一数据源，不建立平行食材表。

固定规模：
- 243 种食材
- 20 个食材分类
- 3 个仓储温区：常温 / 冷藏 / 冷冻

新增：
- 统一食材档案
- 分类名称
- 仓储温区
- 原采购单位
- 库存基础单位
- 保质期
- 净料率
- 易腐等级
- 临期提醒天数
- 仓储处理类型
- 周转速度
- 新鲜度计算
- 批次状态
- 库容健康度
- 临期/当日到期/过期/低品质/高库容预警

批次状态：
- fresh
- near_expiry
- expires_today
- expired

新增库存接口：
- lotRows
- capacitySummary
- inventoryAlerts
- inventoryHealth

门店经营接口新增：
- inventoryLotRows
- inventoryHealth

兼容原则：
- 旧批次没有 batchNo 时读取时自动生成兼容批次号。
- 旧批次没有 storage 时按正式食材分类自动推导。
- 保持原 FEFO（先到期先出）消耗顺序。
- 保持 600kg 常温 / 320kg 冷藏 / 220kg 冷冻默认容量。
- 保持原补货阈值 45% / 15%。
- 不修改供应商报价、采购谈判、物流机制；这些进入 11/26。
- 不修改菜品克重、配方和食品成本算法。
