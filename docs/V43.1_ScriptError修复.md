# V43.1 Script error 修复

已确认根因：

V43 房源市场代码在 `enter()` 中使用：
- `V43_PROPERTY_ICONS`
- `V43_STOREFRONTS`

但 V43 的插入脚本错误地只匹配单行：
`const DESIGN_W = 390;`

当前仓库实际格式是：
```
const DESIGN_W =
  390;
```

因此两个常量没有被插入，但后续代码已经引用它们，
进入房源市场时触发 ReferenceError，Android 端只显示：
`Script error.`

V43.1 使用跨行正则重新插入两个常量，
并新增“定义必须早于使用”的回归测试。
