# V36 门店第一阶段

资料库母版：
- 中式餐饮模拟游戏UI升级资源包
- 餐饮城市经营游戏图标资源包
- 仓库中已经拆出的 premium/store 与运行时门店素材

本阶段不新增生成图，优先复用资料库已导入资源。

## 三状态
1. 无门店
   - 推荐商圈：真实城市动态数据
   - 今日优质房源：真实 propertyMarketSystem
   - 首店预算：根据当前房源实时估算
   - 去选址 / 查看房源

2. 筹备中
   - 门店外观、店名、地址
   - 装修进度
   - 证照数量
   - 招聘覆盖
   - 设备状态
   - 动态下一步建议
   - 开店周转金

3. 营业中
   - 门店真实结构指标
   - 商圈实时需求/客单/竞争/饱和度
   - 包厢管理
   - 员工/菜单/供应链/数据快捷入口

## 固态
卡片结构、按钮、图标槽位、色彩、间距。

## 动态
店名、地址、商圈、资金、房源、预算、装修、证照、员工、设备、
餐位、租金、商圈需求、客单、竞争、饱和度、当前门店。

第一阶段不伪造营业额/利润；真正营业模拟在后续经营核心接入。
