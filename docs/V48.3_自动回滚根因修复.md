# V48.3 自动回滚根因修复

GitHub Actions #82 / #83 虽然显示成功，但 V47/V48 页面并未真正落地。

日志证据：
1. `V48 dynamic floor geometry patches applied`
2. 随后 `HEAD is now at ... Add files via upload`
3. `[recovery-v052] 已对齐旧 updater 的提交`

根因：
`scripts/ci-reconcile-update-race-v052.js` 在 `npm install` 的 postinstall
以及 `npm test` 内执行 `git reset --hard origin/main`，
把刚刚解压和应用的 V47/V48 文件全部回滚。

修复：
- 当仓库根目录存在 `update.zip` 时，恢复脚本立即退出；
- 活动更新期间禁止执行 `git reset --hard`；
- 保留 update.zip 不存在时的旧恢复行为；
- 新增 `v48SafeReconcile.test.js` 防止以后再次回归。

这不是 UI 或房型算法问题，而是更新基础设施覆盖了更新内容。
