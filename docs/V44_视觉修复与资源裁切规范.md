# V44 视觉修复与资源裁切规范

本版没有生成任何新图片。

## 裁切修复
不再批量按网格/猜测坐标裁图。
只从用户资料库原始图表中提取 5 个独立、完整、无遮挡的主体：
- 可用资金
- 当前目标
- 城市通报
- 礼物
- 收藏星星

每张：
- 使用安全外框，不含文字标签
- 先识别完整主体，再保留内部暗部细节
- 统一放入 96×96 透明画布
- 主体四周保留安全边距
- manifest 自动验证主体没有贴边/被截断

房源面积、门宽、排烟、燃气、三相电、竞争等小图标
不再从整张资源表裁切，直接使用项目已有 `propertyIconAtlas`，
保证语义正确、大小一致。

- 房源市场四项概况加入图标和更粗数字
- 房源卡排烟/燃气/三相改成紧凑状态胶囊
- 门店开店流程恢复统一语义图标
- 门店推荐房源星星改用柔和图片星星
- 门店顶部改用无文字城市背景
- 一级标题和关键数字使用更饱满字重
- V43旧裁切资源保留仅用于历史兼容，不再驱动房源硬件图标
