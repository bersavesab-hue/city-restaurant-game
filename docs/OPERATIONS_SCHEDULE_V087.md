# V0.8.7 营业时间与员工排班

本包基于正式 V0.8.6 增量更新。

完成：
- 玩家可以设置真实开门/打烊时间。
- 营业时间直接写入 shop.businessHours，餐厅客流系统立即读取。
- 开门前、打烊后不再产生正常新客流。
- 每名已录用员工自动进入排班表。
- 班次：早班 / 中班 / 晚班 / 停排。
- 每名员工拥有每周固定休息日，可循环调整。
- 实时计算店长、厨师、服务员、收银四类岗位覆盖。
- 某个岗位缺班会真实降低 staffCoverage，从而影响客流承载、排队和出餐。
- 招聘页面增加“营业时间 / 员工排班”入口。
- 新增独立排班管理页面和分页。
- 所有修改立即进入存档。
- 保留 V0.8.6 经营闭环、V0.8.5 管理中心、V0.8.4 动态竞品/NPC 世界。
