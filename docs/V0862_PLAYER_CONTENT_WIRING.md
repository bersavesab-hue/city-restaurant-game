# V0.8.62 玩家内容接线版

基线：V0.8.61  
目标：V0.8.62

本版不重写V0.8.61经营因果闭环和开店筹备中心，只把已经存在的深层后台能力接到玩家界面。

## 新增玩家入口

功能中心新增“经营中心”。经营中心包含四个页签：

- 营销：24类活动、预算、8类渠道开关。
- 会员：真实顾客档案、入会、会员等级与积分。
- 采购：食材选择、比价、供应商选择、议价、下单、收货。
- 成长：品牌等级、成就、3项周目标、14项长期里程碑、管理点。

## 兼容性

- 原存档键不变，不清档。
- 补丁脚本允许在0.8.61应用，也允许0.8.62重复执行自检，不会重复插入口。
- 不接广告、登录、支付、分享、云存档等平台接口。
