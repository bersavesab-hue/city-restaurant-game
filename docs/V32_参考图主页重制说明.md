# V32 参考图主页重制

这版把用户确认的目标图作为新的主页视觉基线，但不把整张截图压到游戏里。

## 新资源
- 干净城市背景
- 7个重新生成的立体商圈图标
- 7个重新生成的商圈详情小图
- 从用户提供目标图中直接裁出的底部导航视觉资源
- 装修入口图标

## 首页结构
顶部HUD → 城市播报 → 当前目标 → 动态城市地图 → 商圈详情卡 → 底部导航

## 动态数据保留
- 城市名
- 天气/温度
- 资金
- 品牌等级/声望
- 时间
- 新闻
- 目标进度
- 商圈人口/需求/客单/店数/饱和度/租金
- 我的店状态
- 商圈点击与进入商圈

## 底栏调整
正式改为：
城市 / 门店 / 装修 / 菜单 / 供应链 / 数据 / 系统

首页使用参考图的底栏资源保证视觉一致；
进入其他页面后仍保持相同的7项功能结构和动态选中状态。
