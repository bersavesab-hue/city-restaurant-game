# V20 主页目标图一比一重构

本轮只重做“城市主页”，不扩展其他未完成系统。

## 按目标图重新实现
- 顶部城市实景缩略图、城市名修改、天气图标、现金卡、动态品牌等级
- 5档时间控制与日期/时段
- 城市通报三段式横幅
- 当前经营目标进度条
- 7个商圈目标图式“图钉 + 深蓝标题 + 白色副标题 + 动态红色徽记”
- 有玩家门店的商圈显示“我的店”
- 底部东门市场式大信息卡
- 六项指标带正式小图标
- 金色“进入商圈”
- 金蓝正式底部导航

## 装修入口调整
独立“装修”底栏已经取消。
装修仍然保留在“门店 → 装修”体系里，并且装修页打开时底栏归到“门店”。

第三个主导航改为“客流”。

“客流”不是占位：
- 点击后回到城市页
- 自动选择当前需求最大的商圈
- 地图显示实时客流热力
- 热力由各商圈真实餐饮需求计算
- 仍可点击任意商圈继续查看

## 动态性
商圈徽记根据：
- demandDeltaRatio
- saturation
- rentIndex
- populationDelta
实时变化。

“我的店”读取真实 business.shops。
当前目标读取真实选址/看铺/谈判/门店/装修/证照/招聘/营业状态。
