# V0.8.51 每日经营目标闭环

基线：V0.8.50  
目标：V0.8.51

## 为什么做这一批

当前已经具备：

- 真实营业数据；
- 日结复盘；
- 首要问题；
- 昨日/前日趋势；
- 调整效果；
- 去处理入口。

但玩家开始新一天时仍缺少一个非常明确的短期追求。

V0.8.51增加“每日经营目标”，让每一天都形成：

今日目标 → 做经营决策 → 营业 → 日结 → 完成/失败 → 连续完成记录 → 下一天新目标。

## 目标不是随机任务

目标直接由上一完整营业日的真实数据生成：

- 第一次营业：拿下第一单
- 没订单：恢复成交
- 现金危险：降低现金压力
- 库存预警：清零预警
- 食材成本率过高：压到42%以内
- 亏损：净利润转正
- 评分偏低：提升到3.8以上
- 经营稳定：利润较昨日提升5%

## 留存机制

不发额外货币，避免经济膨胀。

系统记录：

- goalsCompleted
- goalsMissed
- goalStreak
- bestGoalStreak

后续可以直接接成就、周目标、挑战榜，而不需要重做底层。
