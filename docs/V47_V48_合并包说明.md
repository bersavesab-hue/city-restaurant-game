# V47 + V48 合并上传包

这是一个累计包，直接上传为仓库根目录 `update.zip`。

包含：
- V47 装修页面参考图重构
- V48 动态房型装修引擎

当前仓库是 V46 基线，因此：
- `src/scenes/renovationScene.js` 直接替换为 V47+V48 最终页面
- `src/renovation/floorGeometrySystem.js` 为新增动态房型引擎
- `scripts/apply-v48-dynamic-floor.js` 在 npm install 的 preinstall 阶段，
  对现有 V46 `renovationSystem.js` 和 `propertyNegotiationSystem.js` 做增量升级

这个包不会携带/覆盖：
- competitorFullPackV110
- personNpcFullPackV100
- customerFullPackV100
- easterEggPackV100
- RECOVERY_V052 数据包内容

因此不会再出现“工作流成功但其实上传的是旧恢复包”的情况。
