# V0.8.60 经营核心整合修复版

基线：V0.8.51  
目标：V0.8.60

这是一次集中式逻辑大修，不继续向有冲突的底层叠加里程碑、周任务等新系统。

## 已修复的核心结构问题

1. **双日结**：自动跨日与兼容手动日结统一进入同一个后处理管线。
2. **自动日结漏系统**：补齐财务日报、口碑、商业生态、环境、监管、成长、排名、决策反馈和经营健康度。
3. **假开始营业**：营业日由真实游戏时间自动创建，正式经营页不再出现“开始营业日/手动推进日结”。
4. **昨日状态配今日数据**：只有存在 active 营业日时才显示“今日”；否则四项指标与标题都读取最近完整日结。
5. **旧版日期漂移**：runtime.day 领先世界日期时自动纠偏；正常落后则逐日真实补结算。
6. **每日目标反向惩罚**：删除“利润比昨天+5%”，改为保持盈利及渐进改善目标。
7. **目标挫败过强**：增加 near（接近完成）和 stabilityLevel（经营稳定度）；明显失败只下降1级。
8. **试营业空跑**：必须真实产生3个不同营业日的 financial 数据，重复同日快照自动去重。
9. **连续盈利口径错误**：累计盈利使用 profitDays，连续盈利成就改读 profitStreak。
10. **旧存档新增字段缺失**：经营目标相关新增字段自动补默认值。

## 经营主循环

真实时间推进
→ 自动创建营业日
→ 顾客/订单/成本进入唯一账本
→ 跨日自动 closeDay
→ 唯一后处理
→ 日结复盘
→ 目标判定
→ 决策反馈
→ 成长/成就
→ 下一营业日
