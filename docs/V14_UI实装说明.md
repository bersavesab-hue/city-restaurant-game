# V14 金蓝高保真UI实装说明

这一步不再继续生图，正式把已经确认的四张目标UI变成游戏运行界面。

## 本次目标

### 首页
- 保留高清城市地图
- 去掉左右两排“概览/动态/事件/地块/人口/排行”大按钮
- 顶部改为：城市头像、城市名、日期时间、天气、资金、品牌等级、倍速
- 城市动态改为一条紧凑横幅
- 商圈点位改为金色地点标 + 深蓝标签
- 点击商圈后，底部出现完整商圈卡：人口、需求、客单、餐饮店、饱和度、租金
- 底部导航改成 7 项：城市 / 门店 / 装修 / 菜单 / 供应链 / 数据 / 系统

### 商圈详情
- 去掉旧的“带文字背景图 + 动态文字”叠加，避免重影
- 保留活跃人口、需求、客单、人群结构、时段需求、经营环境
- 底部改成经营适配标签 + “选择该商圈开店”主按钮

### 门店主页
- 包厢区改成 3 个真实包厢 + 1 个添加入口
- 每个已有包厢直接出现改名按钮
- 增加“管理包厢”入口，直接跳到装修页的包厢管理
- 门店改名继续使用已经修好的可编辑弹窗

### 装修页
- 顶部直接显示“保存模板 / 另存模板”，不再做成看得见却不能用的假按钮
- 保存模板和另存模板都真正调用 customizationSystem.saveTemplate
- 门店名称仍可直接点顶部区域修改
- 从门店页点“管理包厢”时，装修页直接进入包厢管理页
- 保留撤销 / 重做

## 一键更新方式

仍然只上传根目录 `update.zip`。

工作流运行 `npm test` 前会自动执行一次 `scripts/apply-v14-ui.js`：
1. 改写现有页面布局
2. 删除自己的 pretest 配置
3. 删除补丁脚本自身
4. 执行全部测试
5. 构建 APK
6. 成功后提交最终代码

所以最终仓库不会长期留下“每次启动都重新打补丁”的逻辑。
