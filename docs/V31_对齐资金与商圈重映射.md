# V31 对齐、资金自适应与商圈重映射

本版处理三个用户明确指出的问题：

1. 详情卡
- 底边直接与底栏顶边对齐；
- 右侧六项指标统一占满可用宽度；
- “进入商圈”按钮保持固定右边距；
- 底部说明自动缩短，不与按钮争空间。

2. 可用资金
- 50,000 -> ¥5万
- 5,000,000 -> ¥500万
- 500,000,000 -> ¥5亿
- 1,260,000,000 -> ¥12.6亿
- 更大数值支持“万亿”
- 资金框本身按右侧剩余空间自适应，不再依赖固定长数字。

3. 商圈分布
- 大学城：左上
- 高新区：右上
- 商业中心：中部
- 老城区：左中
- 城中村：右中
- 工业园：左下
- 东门市场：右下

并修正详情卡左侧商圈小图标映射，避免高新区显示成错误图标。
