# 金融系统 V1.0.3

本版在现有 completeFinanceSystemV0825 与 openingFinanceSystem 上扩展，不另建第二套现金账。

玩家入口：门店 -> 财务 -> 金融中心。

金融中心四页：
- 资金账户：现金、贷款余额、月供、债务压力、融资能力
- 融资贷款：经营周转贷、设备升级贷、扩店发展贷
- 信用授信：300-850动态信用评分、授信额度、利率影响因素
- 还款流水：月供、逾期、补还、提前结清、金融流水

核心规则：
- 盈利稳定、现金储备和按时还款提高信用
- 逾期、亏损和高债务压力降低信用
- 信用决定可借额度与利率
- 贷款本金不进入经营利润，利息计入金融成本
- 月供随游戏月份自动处理
