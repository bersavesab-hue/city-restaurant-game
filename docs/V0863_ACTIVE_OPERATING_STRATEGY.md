# V0.8.63 主动经营决策版

基线：V0.8.62  
目标：V0.8.63

## 核心变化

V0.8.61建立了经营因果：
价格、缺货、损耗、复购、热销菜都会真正影响结果。

V0.8.63开始让玩家主动利用这些因果。

### 首要策略

经营页会根据最近一次完整日结自动挑出一条最值得处理的策略。

优先级大致为：

1. 过期损耗严重：收窄菜单，暂时下架最低销菜。
2. 缺货明显：按当前菜单与真实库存补货。
3. 价格流失明显：对高价高溢价菜做小幅安全降价。
4. 复购弱：把真实热销菜强化为招牌菜。
5. 热销菜和招牌菜不一致：调整招牌菜。
6. 结构稳定：不强行操作，继续观察。

## 不是自动托管

系统只给一条建议。
玩家必须主动点击“执行策略”。

不会自动：

- 贷款
- 开新店
- 解雇员工
- 大额投资
- 连续调价
- 连续补货

每个营业日只允许执行一次一键策略。

## 效果评估

执行策略继续进入原有 decisionFeedback。

第二个营业日会比较：

- 营收
- 利润
- 评分
- 库存预警
- 现金压力
- 复购/价格/缺货等经营信号

从而形成：

发现问题
→ 执行策略
→ 下一营业日
→ 日结验证
→ 再调整
