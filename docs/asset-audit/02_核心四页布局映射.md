# 核心四页布局与素材映射

## 1. 城市首页

顺序固定：

1. 顶部城市状态
   - 城市名 / 日期 / 天气 / 资金 / 品牌
   - 文字动态绘制
2. 城市动态条
   - 背板可代码绘制
3. 城市地图
   - 使用原始高清地图
4. 商圈点位
   - 使用 UI atlas 的 6种 marker
5. 点击商圈后的轻量详情卡
   - 人口 / 需求 / 客单 / 竞争 / 租金
6. 底部导航
   - 统一图标+文字，不使用效果图整块截图

禁止：
- 把完整首页效果图作为背景
- 把城市名、金额、商圈名写死在图片里
- 六个大胶囊悬浮按钮堆在地图两边

## 2. 商圈详情

顺序：

1. 城市背景头图 + 返回 + 查看房源
2. 城市动态
3. 活跃人口 / 当前需求 / 平均客单
4. 消费人群结构
5. 时段需求结构
6. 经营环境
7. 经营适配
8. 收藏 / 选择开店

图片只负责：
- 头图
- 头像
- 固定图标

数据图全部代码画，避免重影。

## 3. 门店页

顺序：

1. 门店名 + 资金
2. 门店主视觉
3. 地址 / 状态 / 改名
4. 包厢相册
5. 开店进度
6. 下一步建议
7. 拓展商圈
8. 底部导航

必须是真功能：
- 门店改名
- 包厢改名
- 新增包厢
- 查看装修
- 证照
- 招聘

## 4. 装修页

顺序：

1. 顶部门店信息 + 保存模板 / 另存模板
2. 装修模板条
3. 大型平面编辑区
4. 右侧风格/灯光/材料/包厢/楼层工具
5. 桌型与数量
6. 实时数据预览
7. 效果预览
8. 确认施工

素材使用：
- 桌椅/设备/绿植/吊灯：从 renovation atlas 裁切
- 模板风格：使用现有模板图
- 包厢门牌：可用atlas固定样式，但名称文字必须动态叠加
- 平面墙体/房间边框：代码绘制，避免死布局
