# V0.8.15 城市 / 商圈 / 房源数据库统一

本轮不重复造房源数据，而是统一现有多套底座：

- 1 座当前经营城市
- 7 个商圈
- 42 条街道（每商圈 6 条）
- 756 个动态潜在铺位
- 保留 336 套旧静态基线房源兼容
- 16 个一级物业大类
- 96 个二级铺型
- 240 个结构模板
- 7 个规模档

新增 `cityPropertyDatabaseV0815.js` 作为统一查询与关系索引层。

动态房源市场仍保留原来的挂牌、撤牌、NPC竞租、价格波动和事件机制，
但玩家拿到的动态挂牌会统一经过完整房源包补全，包含：
一级大类、二级铺型、结构模板、规模档、房东画像、合同模板、
历史用途、挂牌原因、优势、缺陷、物业限制、交易方式和风险字段。

兼容原则：
- 不删除 `propertyData.js`
- 不删除 `propertySystem.js`
- 不改变旧 336 静态房源测试规模
- 不改变 756 潜在地址规模
- 不改变动态市场内部状态格式
- 旧 `propertyTypeId` 继续保留
