# V0.8.6 完整经营闭环

本包严格基于当前正式 V0.8.5 管理中心版继续叠加，不删除或替换管理中心、动态竞品和NPC世界。

完成内容：

- 开店顺序统一为：装修 → 设备 → 证照 → 招聘 → 3天试营业 → 复盘 → 正式营业。
- 试营业进入真实餐厅模拟，客流约为正式营业的78%，真实产生订单、库存消耗、后厨压力、评价和财务结果。
- 3个游戏日后自动进入 `trial_complete`，不会自动正式开业。
- 玩家查看试营业复盘后手动确认正式开业。
- 开店贷款从试营业起激活，还款日真实扣款；现金不足进入逾期，长期逾期进入违约；支持提前还款。
- 租约支持免租期、押付周期、年递增、欠租、严重欠租违约、合同到期、押金抵扣/返还、续租和主动退租。
- 底栏“系统”正式启用：手动保存、标准/大字模式、贷款查看和提前还款、租约续租/退租、重新开局。
- 生命周期在餐厅模拟之后执行，保证跨日时先完成餐厅日结，再处理试营业结束、租金和贷款。
- 保留 V0.8.5 管理中心及其测试。
