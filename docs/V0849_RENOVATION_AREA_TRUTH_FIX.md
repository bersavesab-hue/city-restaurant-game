# V0.8.49 装修面积与交互修复包

基线版本：V0.8.48  
目标版本：V0.8.49

## 面积规则

- 房源“可用面积”是装修系统唯一的总面积来源，建筑面积只用于房源信息展示。
- 多楼层旧存档会按原楼层权重重新分配，所有楼层之和严格等于房源可用面积。
- 后厨、仓储、服务区和堂食区四项相加必须等于本层面积。
- 柱体、楼梯、卫生间和入口消防净空从堂食可摆面积中扣除。
- 餐桌占地包含座椅拉出及服务净空；包厢按基础面积加每座面积计算。
- 房型效率只能降低可摆面积，不能让有效面积大于物理面积。

## 装修界面

- 平面图按当前分区比例实时重画，每个区域直接标注平方米数。
- 可拖动三条白色虚线调整后厨、仓储和服务区面积。
- 调整会自动保留最小堂食面积及现有家具所需面积，避免把有效方案拖成超载方案。
- 主页面积卡显示本层面积、扣除结构后的可摆面积、家具占用与剩余面积。
- “全屏预览”改为真实平面预览，并显示完整面积等式和净空核算。
- 施工按钮采用二次确认，明确报价、当前现金和施工后余额。
- 已完工门店可重新进入升级装修，施工报价按改造差额计算。
