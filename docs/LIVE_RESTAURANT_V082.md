# V0.8.2 餐厅现场模拟

本包是从当前正式 V0.8.1 可直接升级的累计包：
V0.8.15 动态世界 → V0.8.16 动态世界UI → V0.8.2 餐厅现场模拟。

## 现场经营已经不再即时结算

原流程：
顾客出现 → 立刻点单 → 立刻做完 → 立刻结账。

V0.8.2 改为：
到店/外卖顾客出现
→ 堂食先进入等位队列
→ 有匹配餐桌后入座
→ 点真实菜单
→ 进入厨房制作票
→ 按工位容量排队
→ 工位空闲后开始制作
→ 消耗真实库存
→ 随真实制作时间完成
→ 堂食上菜并占桌用餐
→ 用餐结束结账并翻台
→ 自取等待取餐
→ 外卖等待骑手
→ 骑手取餐
→ 配送在途
→ 送达后结算和评价

## 新增现场变量
- 等位桌数
- 当前在座人数
- 餐桌占用率
- 后厨排队单量
- 当前制作工位数量
- 等待骑手外卖
- 配送在途外卖
- 今日弃排
- 今日缺货
- 今日错单/退菜
- 平均等位时间
- 平均出餐时间
- 高峰最大队列
- 高峰最大后厨队列

## 真实影响
- 顾客耐心不足会放弃等位。
- 餐桌满了以后客人不会凭空被接待。
- 同一厨房工位有并发上限。
- 人手不足和世界事件会降低实际厨房效率。
- 缺少配方食材会真实阻断订单。
- 后厨拥堵会拉长出餐时间。
- 员工覆盖不足、高峰、慢出餐会提高错单概率。
- 错单可能退款或退菜，并影响评价。
- 外卖有等待骑手、配送中、送达三个阶段。
- 配送过慢会降低菜品品质和评分。
- 日结会把等位流失、错单、缺货等结果反馈到城市讨论流。
