# V0.8.0 经营接线第一阶段

这一阶段不继续扩数据库，而是把 V0.7 的经营发动机正式接到游戏页面。

## 已完成

- 每一家玩家门店都有独立 RestaurantRuntime 状态。
- 供应商网络作为城市共享资源，门店分别保存菜单、库存、采购单、厨房、前厅、员工、账本、顾客记忆、活动和品牌数据。
- 运行状态写入 `gameState.business.restaurantOperations`，进入统一存档树。
- 主程序启动时读取存档；第一次启动建立存档。
- 跨日自动保存；微信/抖音切后台自动保存；Android 增加 pagehide / visibilitychange 保存。
- “菜单”页面不再是空壳：可选择菜品、上架/停售、设招牌、涨价/降价，显示真实供应链估算成本、毛利与可售份数。
- “供应链”页面不再是空壳：库存、采购单、供应商三个页签；库存低时可执行真实智能补货，真实扣玩家现金并形成库存批次。
- “数据”页面不再是空壳：营业额、利润、订单、顾客、食材成本率、利润率、平均客单、库存、菜单和评分都从真实经营状态读取。
- 新增 V0.8.0 回归测试。

## 下一阶段

V0.8.1 将替换 `storeScene.getOperatingSnapshot()` 的旧简化营业公式，让门店营业页只读取真实订单与真实结算数据，并把时间推进与 RestaurantRuntime 日常营业模拟接起来。
