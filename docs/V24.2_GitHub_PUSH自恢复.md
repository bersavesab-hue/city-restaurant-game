# V24.2 GitHub PUSH 自恢复

本版保持 V24 最终主页、2.5D 新底图、7 个商圈预览图和全部经营逻辑不变。

新增运行时保护：
- 不修改 GitHub workflow 文件；
- 在 GitHub Actions 当前运行过程中向 `GITHUB_PATH` 注入临时 git 包装器；
- 原工作流最后执行 `git push origin main` 时自动最多重试 5 次；
- 每次失败后递增等待；
- 自动 fetch main；
- 远端若有无冲突的新提交，自动 rebase 后继续 push；
- push 成功后原工作流会继续执行 APK Artifact 上传。

该包装器只存在于当次 Actions Runner 的临时目录，不会写入正式游戏代码。
