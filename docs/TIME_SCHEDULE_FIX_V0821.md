# V0.8.21 时间与装修日程完整修复

本包基于正式 V0.8.2，纯增量升级。

修复内容：
- 装修不再依赖进入装修页/门店页才更新。
- 设备到货不再依赖进入相关页面。
- 证照审批不再依赖进入相关页面。
- 装修时间从“按整天检查”升级为分钟级开始/结束时间。
- 装修页进度条改为真实进度，不再固定约56%。
- 装修页显示真实百分比和剩余小时。
- 门店页装修进度统一读取同一套真实进度。
- 主界面时间倍率改为：暂停 / 1× / 5× / 20× / 100×。
- 底层继续兼容旧存档中的2×、10×，避免老存档和既有回归测试失效。
- 100×下按最多30游戏分钟分段模拟，避免跨餐期、跨天时漏算。
- 单帧仍最多吸收1000ms，保持旧时间契约；高倍速通过30游戏分钟分段执行避免漏算。
- 高倍速客流批次上限根据推进分钟数动态扩大，避免18人硬上限拖慢模拟。
- 全局日程变化会参与自动存档和重绘。
- 清理仓库根目录误放的 apply-update.yml，不影响 .github/workflows/apply-update.yml。
