# V0.8.8 员工长期经营系统

基于正式 V0.8.7 增量更新。

本版把“招聘完成后的员工”继续做成长期经营对象：

- 每名员工拥有持久职业等级、职级、经验、绩效。
- 培训需要真实花钱并占用2个游戏日，培训期间员工不参与排班。
- 培训完成后提升岗位相关技能与员工综合技能。
- 支持加薪，真实修改长期月工资；30天内不能重复加薪。
- 支持晋升，按技能与任职天数判定，不允许无条件升级。
- 晋升会提高职级、工资、满意度和忠诚度。
- 支持批准1—3天请假，请假期间真实降低岗位覆盖率。
- 健康差或压力过高时存在低概率自动病假。
- 支持每7天一次沟通关怀，改善情绪、压力、满意度和忠诚度。
- 正常工作累计经验，长期可自然成长技能。
- 团队管理页展示情绪、精力、压力、满意度、忠诚度、离职风险和当前离岗状态。
- 请假/培训状态同时接入 V0.8.7 排班系统和 V0.8.4 NPC 每日状态。
- 原有竞品挖人、压力离职、员工创业逻辑继续保留并与新系统共存。
