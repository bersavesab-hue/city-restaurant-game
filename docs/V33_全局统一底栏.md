# V33 全局统一底栏

修复：城市页底栏和门店/装修/菜单/供应链/数据等页面底栏视觉不一致。

## 统一规则
所有页面只使用同一套底栏：
城市 / 门店 / 装修 / 菜单 / 供应链 / 数据 / 系统

统一：
- 高度
- 深蓝渐变背景
- 顶部蓝色光边
- 图标尺寸
- 字号
- 分隔线
- 黄色选中卡
- 点击热区

只根据当前页面移动黄色选中状态，不再存在“城市页特例”。

## 场景映射
- city → 城市
- shop/propertyMarket/equipment/license/staff → 门店
- renovation → 装修
- research → 菜单
- supply → 供应链
- business → 数据
