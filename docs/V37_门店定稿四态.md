# V37 门店定稿四态

以用户已经定稿的四张门店参考图为唯一门店母版，不再使用其它替代结构。

## 状态
- 0 家门店：无门店工具页
- 1 家未营业：筹备中门店页
- 1 家营业：单门店经营主页
- 2 家及以上：多门店总览；点击门店进入单店或筹备详情

## 无门店
- 横幅
- 资金 / 推荐预算 / 推荐商圈
- 前往选址 / 查看商圈
- 开店流程
- 3 个动态推荐房源
- 今日机会
- 市场动态

## 单店营业
- 门店主图 / 营业状态 / 地址
- 今日营业额 / 净利润 / 顾客 / 评分
- 进入经营 / 门店详情
- 装修 / 员工 / 菜单 / 供应链 / 营销
- 今日门店情况
- 待处理事项
- 热销菜品
- 门店评价
- 扩店机会

## 多门店
- 门店总数 / 总营业额 / 总利润 / 异常门店
- 状态筛选
- 门店列表
- 门店地图 / 人员调配 / 统一采购 / 品牌升级
- 扩张机会

## 筹备中
- 主图 / 状态
- 装修 / 证照 / 招聘 / 设备
- 开店进度
- 下一步建议
- 筹备资金
- 继续筹备 / 继续看商圈
- 扩张机会

所有店名、地址、资金、租金、房源、筹备进度、商圈和经营指标均为动态绘制。
