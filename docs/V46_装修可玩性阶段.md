# V46 装修可玩性阶段

本包是累计补丁：
如果仓库还没有 V45，会先自动应用 V45，再应用 V46。

本阶段不生成新图片，继续使用资料库已有装修素材。

## 新增玩法

### 1. 区域面积
- 后厨比例 ±2%
- 仓储比例 ±2%
- 服务区比例 ±2%
- 堂食区根据前三项自动联动
- 每项显示百分比、实际平方米、允许范围
- 动线模式可在紧凑 / 标准 / 宽松之间切换
- 面积不合法时继续由原系统阻止开工

### 2. 家具与软装
餐桌：
- 2人桌
- 4人桌
- 6人桌
- 8人桌

软装：
- 绿植
- 吊灯
- 屏风
- 等候沙发

每个软装都有：
- 单价
- 数量上限
- 舒适度加成
- 吸引力加成
- 实际计入装修总预算

### 3. 装修评分
新增 0–100 装修评分，综合：
- 舒适度
- 吸引力
- 运营效率
- 布局合法性

同时实时显示预计经营影响：
- 客流倍率
- 客单价倍率
- 服务效率倍率

### 4. 施工队报价
开工不再自动选最便宜施工队。

玩家先进入施工队页，比较：
- 报价
- 工期
- 可靠度
- 施工质量

选择后再正式开工。
