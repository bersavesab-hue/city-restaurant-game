# V0.8.16 动态世界可视化

这是 V0.8.15 + V0.8.16 累计包。即使 V0.8.15 尚未落库，也会先应用四大动态世界底层，再接入可视化页面。

## 城市动态中心

城市主页原“城市播报”现在直接进入完整动态中心，不再只弹一条 Toast。

动态中心四个页签：
- 动态：进行中的事件与历史事件。
- 政策：酝酿、公告、生效、评估、退出中的政策。
- 讨论：人物真实对话与城市社会讨论流合并显示。
- 人物：长期 NPC 池的人物卡。

## 详情能力

事件详情会显示：
- 所属领域
- 当前阶段
- 严重程度
- 起止时间
- 当前实际客流/采购/人工/租金/产能/口碑等影响

政策详情会显示：
- 政策领域
- 当前阶段
- 酝酿→公告→生效→评估→退出完整时间线
- 生效后具体经营影响

讨论详情会显示完整发言；长期 NPC 的对话可以直接进入人物卡。

人物详情会显示：
- 身份
- 年龄
- 情绪
- 精力
- 压力
- 财富
- 性格标签
- 当前记忆数量

## 未读系统

动态、政策、对话、弹幕均拥有独立未读计数。
- 城市主页“城市播报”显示总未读。
- 四个页签显示自己的未读红点。
- 进入对应页签后只清除该类别未读，不会误清其他消息。
- 未读状态进入游戏存档。
