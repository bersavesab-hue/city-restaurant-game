## 更新机制
`update.zip` 只带增量安装器 `scripts/apply-update-patch.js`。工作流先执行安装器，由它将版本从 0.8.9 升至 0.8.10、修改测试清单和必要接线；工作流随后删除安装器，再运行全部测试和 APK 构建。
