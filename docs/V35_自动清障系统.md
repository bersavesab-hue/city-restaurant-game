# V35 自动清障系统

本版本只处理仓库卫生与自动体检，不改城市首页、底栏、资金显示或经营玩法。

## 自动清理

`npm test` 在 GitHub Actions 中运行前会执行：

```bash
node scripts/repo-cleanup.js --ci-auto
```

只会从 Git 索引取消跟踪可以安全重建的生成文件，包括：

- `node_modules/`
- `android/.gradle/`
- `android/build/`
- `android/app/build/`
- `android/app/src/main/assets/game.bundle.js`
- `android/app/src/main/assets/assets/`
- 自动生成的玩家实验室/工程体检报告
- APK/AAB/DEX、日志、临时文件
- 历史错误文件名 `update .zip`

不会自动删除 `src/`、原始 `assets/`、`docs/` 或历史源码覆盖层。

## 自动体检

运行：

```bash
npm run health
```

会检查：

- Git 是否仍跟踪生成垃圾
- `src/main.js` 多版本函数覆盖数量
- 存档是否接入主入口
- 系统页面是否注册
- 一级页面是否仍是占位页
- 测试文件是否全部纳入 `npm test`
- 超大源码模块

报告生成到 `reports/project-health/`，该目录默认不提交 Git。

## GitHub 权限兼容

V35 更新包**不包含任何 `.github/workflows/*.yml`**，因此不会再次触发 GitHub Actions 机器人没有 `workflows` 权限而导致的 push 拒绝。
