# V0.8.61 经营因果闭环版

基线：V0.8.60
目标：V0.8.61

## 这一版解决什么

V0.8.60统一了营业日和日结底层。
V0.8.61开始解决“玩家做了决定，但为什么感觉结果没有明显变化”。

### 顾客链

满意度 / 忠诚度 / 历史访问 / 收藏门店
→ 老客回店概率
→ 回头客率
→ 复购意向
→ 口碑

不再用固定34%概率随机抽老顾客。

### 价格链

菜价
→ 与顾客预算比较
→ 超预算产生真实离店概率
→ 价格流失进入日结
→ 建议玩家检查高价菜与客群匹配

因此涨价不再只有“单价提高”的好处。

### 菜品链

真实销量 + 真实评分
→ 菜品热门度/质量感知
→ 顾客选择倾向
→ 热销菜形成

修复了原版读取不存在的 item.salesQty / item.avgRating 导致销量与评分几乎不参与自动选菜的问题。

### 库存链

备货
→ 实际消耗
→ 缺货
→ 订单流失

备货过多
→ 过期
→ waste费用
→ 净利润下降

过期库存现在不只是一个库存数字，而是真正进入利润表。

### 日结可见结果

日结保存并展示：

- 回头客率
- 新客/回头客
- 平均复购意向
- 价格流失
- 缺货次数
- 排队流失
- 过期食材损耗
- 热销菜及销量

这样玩家调整价格、补货、服务之后，下一营业日可以直接验证变化。
