# V0.8.9 高峰、疲劳、加班与排班冲突

## 高峰期
新增四类实时高峰：
- 早餐高峰 07:00–09:00
- 午餐高峰 11:00–14:00
- 晚餐高峰 17:00–20:00
- 夜间高峰 21:00–23:00

高峰不是装饰。它会改变真实到店需求和员工工作负荷。

## 疲劳
员工实际在岗会消耗精力并增加压力。
高峰、缺编和加班都会加快疲劳。
疲劳会反向降低真实门店承载能力。

## 加班
员工每日实际在岗超过8小时后开始计算加班：
- 记录加班分钟
- 按月薪折算小时工资
- 加班按1.5倍计费
- 加班费进入真实人工成本和现金支出
- 长时间加班降低满意度和健康状态

## 排班冲突
高峰期会检查店长、厨师、服务员、收银岗位覆盖。
培训、请假、病假和休息日都会形成真实班次缺口。

## UI
“营业时间与排班”页面新增：
- 当前高峰
- 当前经营压力
- 平均疲劳
- 排班冲突数
- 今日加班费
