# 菜品 / 食材 / 配方 / 菜单包 V1.0

纯新增底层包，目录 `src/food/`。不覆盖 main、shopScene、Android 入口、package.json 或 workflow。

核心结构：
- 食材池：按粮食、肉禽、水产、乳蛋、豆制品、蔬菜、香辛料、调味、饮品、烘焙、半成品等分类。
- 配方：96 个可直接经营的基础菜品/饮品配方，配方包含克重、工序、口味、备料、烹饪时间、技能要求。
- 菜品变体：每个基础配方默认可生成小份/标准/大份，至少 288 个 SKU 变体。
- 成本：原料市场指数、净料率、加工损耗、能源、包装、人工、平台抽成共同决定成本线。
- 库存：按克消耗，支持缺料判断、可制作份数、替代食材和保质损耗。
- 菜单：顾客预算/口味/忌口/等待时间参与选菜，支持菜单工程四象限。
- 价格：提供生存成本线、参考价慢更新机制，避免一天价格变化让顾客记忆瞬移。

后续可以与顾客包、竞对包、供应商/采购包直接连接。
