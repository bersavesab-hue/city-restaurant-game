# V0.8.46 首店真实营业优化

基线：V0.8.44  
目标：V0.8.46

本包是 **V0.8.45失败包的完整替代品**，不需要先安装V0.8.45。

## 为什么V0.8.45失败

功能补丁本身已经成功应用到GitHub Actions工作区，但旧测试
`tests/updateInfrastructureV0844.test.js`
把项目版本和Android版本硬编码为0.8.44。项目升级到0.8.45后，旧测试把正常升级误判成失败，因此工作流正确阻止了写回main。

## 本包同时解决三件事

1. 保留V0.8.45的首店聚焦优化。
2. 修复旧版本测试硬编码，后续0.8.47、0.8.48不再因同一问题反复失败。
3. 修复试营业的关键断点：
   - `trial_opening`可以使用营业日控制；
   - 营业日页面读取真实门店运行时账本；
   - 订单、顾客、营业额、净利润与门店首页一致。

## 体验目标

玩家完成筹备并点击试营业后，应该立即进入真正的经营阶段，而不是看到
“正式营业后才能开启经营日”。

第一笔订单产生后，门店首页和营业日页面必须显示同一笔真实经营结果。
