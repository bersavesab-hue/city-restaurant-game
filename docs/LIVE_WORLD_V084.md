# V0.8.4 活人世界 + 竞品世界

本轮不再新增“静态数据包”，而是把已有的人物包与竞品包接入每天的城市运行。

## 员工真实生命周期
- 招聘候选人由完整 Person 生成器产生。
- 候选人保留教育/背景/技能/连续性格轴/性格标签/动机/记忆/情绪状态。
- 入职后每日更新：情绪、精力、压力、满意度、忠诚度。
- 真实计算离职风险、外部挖角、创业倾向。
- 离职后直接减少门店覆盖率。
- 少量高创业倾向员工在足够任期后可能离职创业，并进入真实竞品世界。
- 员工情绪/精力/压力会轻度影响门店有效产能，避免只看“人数够不够”。

## 竞品真实世界
- 城市初始化 300 个经营主体。
- 分层：12 个核心竞品、28 个附近竞品，其余背景经营主体。
- 核心每日、附近每周、背景按月/聚合逻辑运行。
- 竞品会观察玩家的：持续盈利、排队、口碑、商圈饱和度、租金、需求变化。
- 可能行动：观察、模仿菜单、跟套餐、降价、优惠券、广告、达人、挖员工、抢铺、开店、收缩、闭店。
- 扩店走原有真实开店流水线，不是瞬间生成。
- 经营不善会出现连续亏损、现金跑道下降、收缩和闭店。
- 竞品行动会形成有限幅的真实客流竞争，最大不会粗暴砍掉一半客流。

## 玩家可见
- 招聘页显示候选人的真实性格标签。
- 招聘页显示团队情绪、压力和高离职风险人数。
- 数据页显示所在商圈竞争压力和真实竞品门店数量。
- 数据页显示员工情绪和高离职风险。
- 竞品开店、闭店、员工离职/创业会进入城市新闻。

## 数值保护
- 竞品对玩家客流倍率限制在 0.86–1.02。
- 员工状态产能倍率限制在 0.72–1.08。
- 离职需要较高风险阈值，不会随机天天辞职。
- 创业需要高创业倾向 + 至少45天任期，概率保持低频。
