# V0.8.3 基础修复包

本版本不继续堆新内容，优先修复 V0.8.2 全局检测发现的高优先级运行漏洞。

## 已修复

1. **高频同步存档**
   - 自动存档改为脏标记 + 20 秒节流。
   - 切后台与主动 `save()` 仍立即落盘。
   - 避免 10× 倍速营业时频繁 `setStorageSync` 引发顿挫。

2. **经营欠款无限挂账**
   - 房租、工资、水电、营销、合规费用分类形成应付账款。
   - 后续现金会自动按优先级偿还欠款。
   - 欠款逾期会逐级降低经营产能。
   - 门店页显示待付经营款与逾期天数。

3. **天气/周末/客流口径不一致**
   - 真实门店到客改读 `demandSystem.getDemandBreakdown()`。
   - 商圈 UI 与真实到客共用天气、周末口径。
   - 删除错误的 `storm` 判断，`heavyRain` 由统一需求系统处理。

4. **动态世界六类“只显示不生效”修正接线**
   - 平台成本 -> 外卖佣金。
   - 合规成本 -> 真实固定成本和利润。
   - 外卖需求 -> 顾客渠道选择。
   - 营销效率 -> 营销客流增益。
   - 口碑影响 -> 评分/口碑传播。
   - 检查风险 -> 经营产能干扰。

5. **24 小时营业漏洞**
   - 增加营业时段解析。
   - 默认 06:00–23:00。
   - 支持普通营业时段与跨午夜营业时段。
   - 闭店后停止生成新客，但现场已有订单仍继续完成。

6. **首页目标流程覆盖错误**
   - 最终绘制层改为读取 `getHomeGoalState().steps`。
   - 不再显示错误的“选址→装修→试营业→经营→签约”。

7. **版本与仓库卫生**
   - 正式版本升级为 0.8.3。
   - restaurantOperations 存档版本统一到 0.8.3。
   - 删除仓库根目录误传的 `apply-update.yml`，保留真正的 `.github/workflows/apply-update.yml`。

## 本包刻意没有做

NPC 人物引擎和竞品人口模拟属于下一阶段的大型接线，不与基础修复混包，避免改动面过大导致新一轮连锁故障。
