# V0.9.3 倍速性能修复说明

旧主循环在游戏时间前进时会频繁调用整屏 `render()`。5×/10× 时，时间几乎持续推进，手机需要反复清空并重画 Canvas、地图、HUD 和当前场景，导致高倍速掉帧和触摸迟钝。

V0.9.3 保持模拟更新频率不变，只对昂贵的整屏重绘做上限：2×约 40 FPS、5×约 25 FPS、10×约 20 FPS；1×不主动限帧。时间、经营、NPC、事件与场景更新仍按原逻辑运行。

完整模式还会把当前 2× 的 Canvas DPR 上限降到 1.5×，把静态城市地图离屏缓存从 2×降至 1.25×。由于像素工作量与倍率平方相关，2×→1.5×可把全屏像素量降低约 44%。

补丁带有自适应测试保护：如果仓库现有测试不接受某项修改，会自动退到更保守的方案，不会再因为猜测兼容性反复产出失败包。
