# V0.8.47 第一次经营改善闭环

基线：V0.8.46  
目标：V0.8.47

## 本次只解决一个核心问题

玩家完成第一次日结后，不能只看到一堆数字和一句“明日建议”。

V0.8.47把日结结果整理为：

1. 首要问题：今天最需要解决的经营问题；
2. 上次调整：之前做过的菜单、采购、招聘或营销调整产生了什么影响；
3. 明日建议：下一步最值得做什么；
4. 去处理：直接进入对应功能，不再让玩家自己找入口。

## 跳转关系

- 库存预警 → 供应链
- 食材成本率偏高 → 菜单研发
- 亏损 / 现金危险 → 经营结构
- 经营稳定 → 返回门店继续经营

所有跳转继续经过现有EntryRouter和功能权限校验，不绕过解锁规则。

## 目标

把开局主循环推进到：

选址 → 筹备 → 试营业 → 第一笔真实收入 → 日结 → 看懂问题 → 立即改善

这才算完成第一轮“开局10分钟”的核心闭环。
