# V48.3 修复“Actions成功但APK仍是旧装修页”

根因已经确认：
`scripts/ci-reconcile-update-race-v052.js` 在 `postinstall`
阶段执行 `git reset --hard origin/main`。

update.zip 解压后，V47/V48 文件其实已经存在，甚至 preinstall
测试也已经通过；随后 postinstall 又把工作区重置回旧 main，
因而最终 APK 构建的是旧 V45/V46 装修页面。

V48.3 修复：
- PATCH_MANIFEST 声明 `preserve_workspace: true`
- recovery 脚本识别当前是直接验证补丁
- 直接补丁不执行 `git reset --hard`
- 非直接补丁仍保留原有 V0.5.2 updater race 处理逻辑
- 新增回归测试，明确检查最终场景必须包含 V47+V48 标记
- 明确禁止最终场景重新使用 v45_layout_kitchen / v45_layout_dining
