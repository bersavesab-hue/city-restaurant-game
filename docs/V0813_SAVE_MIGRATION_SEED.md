# V0.8.13 存档 / 版本迁移 / 随机种子

本版本是 26 步开发路线的 4/26。

## 核心改动

- 保留原存档键 `city_restaurant_save_v1`，旧玩家不需要迁移文件名。
- 外层存档格式从 V1 升级到 V2；游戏状态内部 `version: 1` 保持兼容，不强制废弃旧存档。
- 支持 V1 envelope 和更早期裸 `gameData` 自动迁移。
- V2 存档增加稳定校验值；主存档损坏时自动回退到上一份有效备份。
- 每次正常覆盖主存档前保留上一份有效备份。
- 新增全局主随机种子与命名空间派生种子接口，为后续事件、顾客、供应商等随机系统提供稳定可重放基础。
- 旧 `world.simulation.seed` 不删除、不覆盖；旧系统显式设置 seed 时继续优先使用。
- 新游戏生成新的主种子，存档读写后保持不变。

## 兼容原则

- 不修改 `.github/workflows`。
- 不在 ZIP 中直接覆盖 `package.json` / `package-lock.json`。
- 保留 V0.8.3 自动存档节流标记和 20 秒节流行为。
- 保留旧存档键名，避免升级后看不到老存档。
- Android SDK runner 的 `tools` 兼容处理仅作用于当次临时 Runner，不进入仓库。
