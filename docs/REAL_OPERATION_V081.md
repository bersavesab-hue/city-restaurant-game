# V0.8.1 真实营业循环

本包针对当前已经成功落库的 V0.8.0 制作，不再重复 V0.8.0 文件。

## 本阶段完成

- 主游戏时间推进正式驱动所有“营业中”玩家门店。
- 顾客到店率由商圈需求、餐厅数量、餐段、饱和度、评分、品牌、营销、天气、员工覆盖率共同决定。
- 到店顾客调用现有顾客引擎，真实选择菜单中的菜品。
- 每笔订单进入既有订单/厨房/库存/结算/评价链。
- 食材按真实配方扣减。
- 营业额来自真实订单。
- 食材成本来自真实库存批次成本。
- 房租、人工、水电、营销按游戏时间逐步计提。
- 真实订单收入进入玩家现金。
- 库存低时每120游戏分钟最多触发一次真实智能补货。
- 采购继续真实扣除玩家现金。
- 经营游标与日结快照进入门店存档。
- 保留最近45个日结快照。
- 修复 V0.8.0 使用临时日历算法的问题，并自动迁移已有门店库存/采购单日期。
- 外卖包装成本正式进入经营账本。
- 门店页删除“营业额×36%食材成本”和“营业额×5.5%水电”两条旧假公式。
- 多门店页面因复用同一营业快照，汇总营业额/利润也同步变为真实账本数据。
