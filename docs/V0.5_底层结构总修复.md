# V0.5 底层结构总修复

本补丁修复早期若干 update.zip 把新模块写到仓库根目录、而真实 Android 游戏从 `src/` 打包的问题。

修复原则：
- 不覆盖已经修好的 `src/scenes/shopScene.js`。
- 不覆盖 `src/main.js`、`android/entry.js`。
- 不覆盖现有动态房源核心 `propertyMarketSystem/propertyData/propertySystem`。
- 将 Foundation、人物、房源扩展、通用系统、彩蛋迁移到 `src/`。
- 累计带入已经正确的竞对 V1.1 和顾客 V1.0，防止缺包。
- `pretest` 只删除此前错误补丁生成的已知根目录文件，不删除未知文件。
- 测试全部改为从真实 `src/` 路径加载。

这是一包“收口修复”，不是新增玩法包。应用后再继续后续菜品/食材等模块。
