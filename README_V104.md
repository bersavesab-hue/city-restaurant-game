# V1.0.4 一体化修复包

本次不是只补客流字段，而是同时完成：

1. 商铺经营形态：摊位 / 外卖档口 / 微型餐馆 / 小型餐馆 / 中型餐馆 / 大型餐饮。
2. 真实客流漏斗：经过 → 目标客群 → 注意 → 兴趣 → 尝试进店 → 排队 → 成交 → 流失。
3. 房源详情自动显示经营形态、堂食资格和座位上限。
4. “数据”页面改成四个二级页：门店概览 / 客流漏斗 / 商圈分析 / 流失原因。
5. 安装器不再依赖单个固定文本锚点；修改后即时语法检查，单文件失败会恢复原文件。
6. 不覆盖 package.json，不修改 GitHub workflow，不新增 npm test 依赖。

上传方法：只把此压缩包重命名/上传为仓库根目录 `update.zip`。
