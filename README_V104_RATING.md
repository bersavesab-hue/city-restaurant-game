# V104 统一评级与数据可视化

本更新建立在 V103 金融系统之后，不新增独立“大数据页”，评级分别进入原有员工、菜单、门店详情与品牌成长页面。

## 统一规则

- 底层统一 0–100 连续分。
- 员工：能力 Lv.1–50，并分为新手 / 熟练 / 骨干 / 资深 / 专家 / 大师；原有岗位职级继续保留，不互相覆盖。
- 菜品：D / C / B / A / S，维度为口味、卖相、成本、出餐、复购、稳定。
- 门店：D / C / B / A / S 的经营评级 + 1–5 星消费者口碑，双轨显示；维度为菜品、服务、环境、卫生、性价比、等位。
- 品牌：Lv.1–20 + 影响力阶段，维度为知名度、口碑、忠诚、一致性、规模、扩张。
- 所有评级返回本期分数、上期分数、变化方向、优势与短板，可供排行榜、奖项、研发和经营反馈继续复用。

## 页面分流

- 招聘页：候选人显示能力等级、段位、综合分。
- 团队管理：在职员工显示能力等级与段位，不再只看“技能/绩效”。
- 菜单：每道菜直接显示评级徽章和综合分。
- 门店详情：新增“评级”二级标签，集中查看门店六维、菜品 Top、团队等级和主要短板。
- 经营中心 → 成长：品牌成长摘要直接显示统一品牌评级。

## 数据原则

优先读取项目已有真实字段；字段缺失时使用中性基线，避免把“没有数据”误判成 0 分。评级本身是解释层，不会凭空增加营业额或修改经营结果。
