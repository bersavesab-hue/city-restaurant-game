餐饮项目代码清理机器人 V2（失败修正版）

这版与上一版的关键区别：
1. 不再自动把 V081/V082 源码改名，避免误改正在使用的文件。
2. 不再在补丁阶段重复执行 npm test / Android JS build；交给现有 GitHub 工作流统一验证。
3. 只有“确定未被任何当前代码/package/workflow引用”的旧版本、旧修复脚本、备份、副本、临时文件才删除。
4. 同一家族多个版本：当前被引用的版本保留；未引用兄弟版本删除。
5. 如果整个版本家族都没有引用，保留最高版本作为安全锚，只删更老版本。
6. 旧 pretest 钩子只有目标脚本已经不存在时才移除，不再暴力删除仍在工作的修复逻辑。
7. 生成 cleanup-report.json，方便继续做第二阶段“活代码统一命名”。

使用：把本 zip 作为仓库根目录 update.zip 上传。
